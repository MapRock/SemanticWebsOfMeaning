| SKOS term                 | Category          | What it means                                                    | Practical use                                                                                |
| ------------------------- | ----------------- | ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `skos:Concept`            | Core structure    | A vocabulary concept or term.                                    | One item in a controlled vocabulary, such as `:BusinessIntelligence` or `:StrategicAccount`. |
| `skos:ConceptScheme`      | Core structure    | A vocabulary, taxonomy, glossary, thesaurus, or controlled list. | The whole vocabulary, such as `:SkillVocabulary` or `:CustomerSegmentScheme`.                |
| `skos:inScheme`           | Core structure    | Says a concept belongs to a concept scheme.                      | Places `:BusinessIntelligence` inside `:SkillVocabulary`.                                    |
| `skos:hasTopConcept`      | Core structure    | Says a scheme has a top-level concept.                           | The concept scheme points to one of its main entry points.                                   |
| `skos:topConceptOf`       | Core structure    | Says a concept is a top-level concept of a scheme.               | The concept points back to the scheme as a top concept.                                      |
| `skos:prefLabel`          | Labeling          | The preferred human-readable label.                              | The official display name, usually one per language.                                         |
| `skos:altLabel`           | Labeling          | Alternate label, synonym, abbreviation, or common phrase.        | “BI” for “Business Intelligence.”                                                            |
| `skos:hiddenLabel`        | Labeling          | Hidden search label.                                             | Misspellings, old labels, or variants useful for search but not display.                     |
| `skos:notation`           | Labeling / codes  | A code or symbolic identifier for a concept.                     | Product category code, industry code, status code, or classification code.                   |
| `skos:definition`         | Documentation     | A definition of the concept.                                     | Business glossary definition.                                                                |
| `skos:scopeNote`          | Documentation     | Explains how the concept should be used.                         | Usage boundaries, exceptions, or when to apply the term.                                     |
| `skos:note`               | Documentation     | A general note about the concept.                                | Miscellaneous explanation.                                                                   |
| `skos:example`            | Documentation     | An example of how the concept is used.                           | Sample use case or example item.                                                             |
| `skos:historyNote`        | Documentation     | Historical note about the concept.                               | Explains past usage or origin.                                                               |
| `skos:changeNote`         | Documentation     | Note about a change to the concept.                              | Records edits, revisions, or governance changes.                                             |
| `skos:editorialNote`      | Documentation     | Note for editors or maintainers.                                 | Internal stewardship or review note.                                                         |
| `skos:broader`            | Semantic relation | Points to a broader concept.                                     | “Sedan” broader “Car” in a vocabulary.                                                       |
| `skos:narrower`           | Semantic relation | Points to a narrower concept.                                    | “Car” narrower “Sedan.”                                                                      |
| `skos:related`            | Semantic relation | Points to an associated concept that is not broader/narrower.    | “Data Governance” related to “Data Quality.”                                                 |
| `skos:broaderTransitive`  | Semantic relation | Transitive broader relationship.                                 | Useful for broader hierarchy traversal. Usually inferred or used carefully.                  |
| `skos:narrowerTransitive` | Semantic relation | Transitive narrower relationship.                                | Useful for narrower hierarchy traversal. Usually inferred or used carefully.                 |
| `skos:semanticRelation`   | Semantic relation | General superclass of broader, narrower, and related.            | Rarely used directly in simple examples.                                                     |
| `skos:exactMatch`         | Mapping           | Two concepts in different schemes are effectively the same.      | Map your `:BI` concept to another vocabulary’s equivalent concept.                           |
| `skos:closeMatch`         | Mapping           | Two concepts are very similar but not guaranteed identical.      | Useful when terms overlap but do not perfectly match.                                        |
| `skos:broadMatch`         | Mapping           | A matching concept in another scheme is broader.                 | Your term maps to a broader external category.                                               |
| `skos:narrowMatch`        | Mapping           | A matching concept in another scheme is narrower.                | Your term maps to a narrower external category.                                              |
| `skos:relatedMatch`       | Mapping           | A matching concept in another scheme is related.                 | Cross-vocabulary association without equivalence.                                            |
| `skos:mappingRelation`    | Mapping           | General superclass of mapping relationships.                     | Rarely used directly in simple examples.                                                     |
| `skos:Collection`         | Grouping          | A labeled collection of concepts.                                | Groups concepts without making a hierarchy.                                                  |
| `skos:OrderedCollection`  | Grouping          | A collection where order matters.                                | Ordered lists such as beginner/intermediate/advanced.                                        |
| `skos:member`             | Grouping          | Concept belongs to a collection.                                 | Adds a concept to a collection.                                                              |
| `skos:memberList`         | Grouping          | RDF list used by ordered collections.                            | Maintains concept order in an ordered collection.                                            |

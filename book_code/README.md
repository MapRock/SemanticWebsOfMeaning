# *Semantic Webs of Meaning* — Supplemental Material

This folder contains supplemental material for *Semantic Webs of Meaning: Building Contextual Knowledge Graphs for Deduction and Integration* by Eugene Asahara, published by Technics Publications.

The book refers to files in this folder using paths beginning with `book_code/`.

The purpose of this material is to extend the book beyond the limits of the printed page. It includes examples, tutorials, appendices, code, figures, references, and explorations of topics that benefit from more detail or are likely to evolve as knowledge-graph and AI technologies change.

The book provides the conceptual foundation. This repository is the place to experiment, dig deeper, and follow the ideas as the technology continues to develop.
